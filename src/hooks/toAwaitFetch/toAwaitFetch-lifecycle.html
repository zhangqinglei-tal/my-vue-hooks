生命周期阶段说明

1. 请求准备阶段

  • 合并配置：全局配置 + 请求配置（请求配置优先级更高）
  • 处理请求头：支持函数动态生成 headers
  • 构建 URL：baseURL + url

2. 请求发送阶段

  • 超时控制：如果设置了 timeout，启动超时定时器
  • 发送请求：使用 fetch API 发送请求

3. 响应处理阶段

  • 网络检查：捕获网络异常、跨域错误
  • 超时检查：检查是否超时
  • 解析响应：根据 responseType 解析数据（json/text/blob/arraybuffer/formData）
  • 状态码验证：使用 validateStatus 验证 HTTP 状态码
  • 响应内容验证：使用 validateResponse 验证业务逻辑
  • 数据转换：使用 transformResponse 将原始响应数据转换为业务使用的格式（仅在 validateResponse 验证通过后执行）

4. 错误处理阶段

  • HTTP 错误：validateStatus 返回 false → 触发 onHttpError → 错误类型 'http'
  • 业务错误：validateResponse 返回 false → 触发 onBusinessError → 错误类型 'business'
  • 网络错误：网络异常、跨域 → 触发 onNetworkError → 错误类型 'network'
  • 超时错误：请求超时 → 错误类型 'timeout'

5. 重试机制

  • 重试条件：
    • retry.enabled === true
    • attempt < maxRetryCount
    • shouldRetry 返回 true（如果提供了自定义函数）
  • 重试流程：
    1. 检查是否满足重试条件
    2. 等待 delay 毫秒
    3. 重新发送请求
    4. 重复上述流程

6. 结果返回阶段

  • 成功：返回 FetchResult，数组格式 [data, undefined, true]
    • 如果配置了 transformResponse，返回转换后的数据
    • 如果未配置，返回原始响应数据
  • 失败：返回 FetchResult，数组格式 [undefined, error, false]

7. 结果处理方式

  • 链式调用（sendGet/sendPost）：
    • .then() - 处理成功
    • .catchHttp() - 处理 HTTP 错误
    • .catchBusiness() - 处理业务错误
    • .catchNetwork() - 处理网络和超时错误
  • 解构（所有方法）：
    • const [data, error, success] = await ...
  • 统一处理方式（所有方法）：
    • 所有方法都返回 FetchResultPromise，支持链式调用和解构
    • 不再抛出错误，错误信息包含在数组的第二项 FetchResult[1] 中
