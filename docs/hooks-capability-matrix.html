Vue Hooks 能力矩阵

调用请求的表格 Hook， vueuse、ahooks 无此功能

分类 能力点 说明 适用场景
核心必备 响应式状态管理（loading/data/error） 实时反映请求状态和结果 所有表格请求场景
灵活的请求适配（axios/fetch/自定义） 兼容多种请求方式，适配不同项目技术栈 不同技术栈项目
自动请求机制（immediate） 支持配置初始化自动请求，减少手动调用 页面初次加载请求
智能参数构建 自动组装请求参数，包括分页、过滤等 所有表格场景
响应式参数同步 监听参数变化，自动触发请求更新 搜索、筛选交互场景
加载状态管理 自动维护请求的 loading 状态 所有表格场景
常用增强 自动分页参数构建 自动构建分页相关请求参数 服务端分页场景
分页状态管理 统一管理分页相关状态（当前页码、每页条数、总记录数） 所有分页表格场景
分页参数格式适配 支持自定义分页参数字段名（page/pageNum、size/pageSize） 不同后端接口规范
分页功能开关 支持禁用分页功能 无分页需求场景
请求生命周期钩子（beforeFetch/afterFetch） 提供请求前后拦截器，支持参数预处理和响应后处理 日志、埋点、数据转换
灵活的数据提取 支持自定义响应数据字段路径（如 result.data.list），支持使用后端的页码来定义当前页用于校正页码 不同后端响应结构、前后端页码不一致需要校正的场景
错误处理机制 提供错误处理钩子，支持自定义错误处理逻辑 统一错误处理流程
手动触发刷新 支持手动触发请求刷新 数据更新后刷新场景

静态数据表格 Hook

分类 能力点 说明 适用场景 ahooks useTable
核心必备 多格式数据源兼容 支持响应式引用（ref）和普通数组等多种数据格式 不同数据源格式场景 ✅ 支持
自动响应式更新 内置数据源监听机制，数据变化时自动触发更新 数据源动态变化场景 ✅ 支持
响应式数据返回 返回的数据集具备响应式特性，与数据源保持同步 所有静态表格场景 ✅ 支持
常用增强 灵活的分页配置 支持自定义初始页码（pageIndex）和每页大小（pageSize） 自定义分页需求 ✅ 支持
自动分页计算 内置分页算法，自动处理数据切片逻辑 所有分页场景 ✅ 支持
可选分页模式 支持禁用分页模式，设置为 false 时返回完整数据集 无分页需求场景 ✅ 支持
智能页码跳转 当数据源变化或页码切换导致当前页为空时，自动回退至上一页 数据删除或过滤后场景 ⚠️ 需手动处理
客户端搜索/过滤 支持按指定列进行搜索过滤 前端搜索场景 ✅ 支持
多种搜索模式 提供模糊匹配、正则表达式、完全匹配、自定义过滤函数 不同搜索需求场景 ⚠️ 支持模糊匹配、正则匹配
自动过滤更新 自动监听过滤配置变化并实时更新结果 实时搜索场景 ✅ 支持
过滤后自动重置页码 过滤条件变更时自动重置至第一页 搜索交互场景 ✅ 支持
字段排序 支持按指定字段进行排序 所有排序场景 ✅ 支持
自定义排序函数 支持自定义排序函数，满足复杂排序需求 复杂排序场景 ✅ 支持（sorter）
数据处理钩子 过滤后的数据支持自定义处理逻辑 数据扩展场景 ⚠️ 需手动处理
操作方法 提供更新当前页、切换页码、修改排序规则等便捷方法 程序化控制场景 ✅ 支持

对比说明

  • ✅ 支持：功能完整支持
  • ❌ 不支持：功能不支持
  • ⚠️ 部分支持或需配合其他功能：需要额外配置或配合其他 Hook 使用

请求 Hook

分类 能力点 说明 适用场景 VueUse useFetch ahooks useRequest
核心必备 响应式状态管理（loading/data/error/statusCode） 实时反映请求状态和结果 所有 HTTP 请求场景 ✅ 支持 ✅ 支持
请求参数配置（url/method/headers/body/params/immediate） 灵活传参可复用 大部分场景 ✅ 支持 ✅ 支持
请求触发方法（send） 显式触发请求 手动请求模式 ✅ 支持（execute/refresh） ✅ 支持（run）
请求取消（AbortController） 防止路由切换时数据污染 长耗时请求 / 组件卸载 ✅ 支持（abort） ✅ 支持（cancel）
错误捕获与统一处理 网络/HTTP错误捕获 + 统一 handler 通用错误上报或提示 ✅ 支持（基础错误处理） ✅ 支持（完善的错误处理机制）
数据格式化（transform） 响应数据统一结构 多组件复用同一数据结构 ✅ 支持（onFetchResponse） ✅ 支持（formatResult）
常用增强 重试机制（次数/间隔） 对临时错误自动恢复 弱网络下的稳定性提升 ❌ 不支持 ✅ 支持（retry/retryInterval）
自动/手动请求模式切换 immediate 控制 页面初次加载请求与交互触发请求 ✅ 支持（immediate） ✅ 支持（manual）
缓存机制（内存或 storage） 避免重复请求同一数据 Tab 切换 / 刷新保留数据 ❌ 不支持 ✅ 支持（cacheKey/cacheTime）
防抖 / 节流 控制频繁请求 搜索建议 / 滚动加载 ❌ 不支持 ✅ 支持（debounceWait/throttleWait）
分页 / 无限加载支持 内置分页状态与方法 列表 / feed 流场景 ❌ 不支持 ⚠️ 需配合 useInfiniteScroll 等
生命周期钩子（onBefore/onSuccess/onError/onFinally） 外部注入行为 日志、埋点、UI控制 ⚠️ 部分支持（onFetchResponse/onFetchError） ✅ 支持（onBefore/onSuccess/onError/onFinally）
高级拓展 请求队列 & 并发控制 同时请求数限制或排队执行 批量任务、后台任务调度 ❌ 不支持 ❌ 不支持
重复请求合并 相同请求自动合并为一次 高并发相同数据拉取 ❌ 不支持 ⚠️ 通过 cacheKey 间接支持
定时轮询（Polling） 定时自动刷新 实时监控 / 聊天列表 ❌ 不支持 ✅ 支持（pollingInterval）
页面隐藏时取消当前请求 基于 Page Visibility API 检测页面不可见时中断请求 减少后台无效资源消耗 ❌ 不支持 ❌ 不支持
页面重新获取焦点时重新请求 在页面可见时自动刷新数据 确保数据最新 ❌ 不支持 ✅ 支持（refreshOnWindowFocus）
网络重连后自动重新发起请求 监听 `online` 事件，在网络恢复时重新请求 弱网络或离线场景 ❌ 不支持 ❌ 不支持
